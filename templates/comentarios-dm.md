# Template — Comentários e DMs

## Resposta educativa geral

Estrutura:

1. **Acolhimento curto** — reconhecer a dúvida sem presumir diagnóstico.
2. **Limite seguro** — deixar claro quando não é possível interpretar o caso pela rede social.
3. **Informação geral útil** — uma ou duas frases, somente se não induzir conduta individual.
4. **Próximo passo** — direcionar para equipe assistente/canal adequado.

## Quando houver possível urgência

Não conduzir triagem detalhada por DM. Priorizar uma orientação objetiva para seguir o plano de urgência fornecido pela equipe assistente ou procurar atendimento apropriado conforme o contexto local.

## Evitar

- “Parece ser…”
- “Você deve tomar/parar…”
- “Com esse valor, precisa/não precisa…”
- cálculo de prognóstico individual;
- garantir que o sintoma é benigno;
- solicitar sequência de dados clínicos com a finalidade de fechar diagnóstico em DM.

## Tom

Humano, breve, profissional e não defensivo. O limite deve soar como segurança clínica, não como recusa burocrática.
