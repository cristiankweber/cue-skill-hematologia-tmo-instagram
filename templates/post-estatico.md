# Template — Post estático

## Quando usar

Uma única ideia, mensagem, dado ou conceito que não exige sequência didática longa.

## Estrutura

### Arte
- Headline de até duas linhas.
- Subheadline opcional para contexto.
- Um elemento visual dominante.
- Evitar miniartigo dentro da imagem.

### Legenda
1. Abrir contextualizando por que a mensagem importa.
2. Explicar o conceito em linguagem adequada ao público.
3. Incluir limite/variabilidade quando clinicamente relevante.
4. Fechar com um CTA único.

## Visual

- Base dark-teal/grafite.
- Dourado/âmbar apenas para ênfase.
- Branco/cinza-claro para leitura.
- Foto humanizada com luz quente OU infográfico minimalista, conforme a pauta.

## Entrega

Headline da arte, subheadline opcional, direção visual, legenda, CTA, fontes, checklist e validação médica.
