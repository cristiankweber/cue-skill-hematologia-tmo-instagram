# Testes de roteamento visual — v3

Use estes cenários para verificar se a skill escolhe um ativo por **função comunicacional**, não por preferência estética.

## VR-01 — Quimerismo para pacientes
**Pedido:** “Faça um carrossel explicando quimerismo.”  
**Esperado:** âncora editorial Dicionário do Transplante; visual VIS-002 se houver foto pessoal. Não escolher palestra.

## VR-02 — Medo antes do transplante
**Pedido:** “Quero um Reel sobre o medo de iniciar o TMO.”  
**Esperado:** modo narrativo-humanizado + REEL-001 como referência de presença; fala íntima, não aula.

## VR-03 — Guideline nova
**Pedido:** “Faça um post sobre uma guideline nova para profissionais.”  
**Esperado:** VIS-003 (rigor/bastidor) ou VIS-004 se contexto de aula; pesquisar fonte atual antes do texto.

## VR-04 — Convite para congresso
**Pedido:** “Faça uma arte anunciando minha palestra.”  
**Esperado:** VIS-004; pouco texto; preservar microfone, gesto e expressão.

## VR-05 — Post institucional
**Pedido:** “Quero uma capa sobre quem sou e como trabalho.”  
**Esperado:** VIS-005; presença institucional acolhedora; headline curta.

## VR-06 — Chamada para carrossel de vacinas
**Pedido:** “Crie um Story chamando para meu post novo de revacinação.”  
**Esperado:** STORY-001 como referência de formato e identidade; não copiar intervalos clínicos antigos sem revalidar.

## VR-07 — Foto com paciente
**Pedido:** “Use a foto em que estou com a paciente.”  
**Esperado:** verificar/solicitar confirmação de autorização/direitos antes de recomendar publicação. Não inferir consentimento a partir do upload.

## VR-08 — Tema puramente mecanístico
**Pedido:** “Explique incompatibilidade ABO maior em um carrossel.”  
**Esperado:** priorizar infográfico; foto pessoal só se adicionar contexto. Não forçar VIS-001/VIS-005 apenas para mostrar o médico.
