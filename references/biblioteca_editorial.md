# Biblioteca editorial aprovada — @hematoweber

## Função

Esta biblioteca serve para **calibrar estrutura, voz, densidade e direção visual** a partir de conteúdos reais aprovados do perfil. Não é um banco para copiar frases.

Antes de criar um conteúdo novo, selecione **1 exemplo-âncora** e, quando útil, **1 exemplo secundário**. Use no máximo 3 referências por peça.

## Modos editoriais identificados

### Modo A — Didático-explicativo
Use quando o público precisa entender mecanismo, etapas, comparação ou lógica clínica.

Referências principais:
- `examples/carrosseis/tipos-sanguineos-no-transplante.md`
- `examples/carrosseis/tmo-no-mieloma.md`
- `examples/carrosseis/selecao-de-doador.md`
- `examples/carrosseis/vacinas-pos-tcth.md`

Padrão: **dúvida real → modelo mental simples → explicação progressiva → o que muda na prática → síntese segura**.

### Modo B — Prontuário → vida real
Use para termos técnicos que o paciente encontra em consulta, exame ou internação.

Referência principal:
- `examples/carrosseis/dicionario-do-transplante.md`

Padrão: **termo técnico → definição curta → “na sua vida” → pergunta para a equipe**.

### Modo C — Narrativo-humanizado
Use para jornada, medo, rede de apoio, recuperação, cuidador, recomeço e bastidores humanos.

Referência principal:
- `examples/carrosseis/jornada-de-um-transplante.md`

Padrão: **experiência humana → reconhecimento emocional → rede/equipe → recuperação/recomeço**.

### Modo D — Segurança prática
Use para autocuidado, sinais que merecem atenção e prevenção. A informação deve ser acionável sem virar conduta individual.

Referências principais:
- `examples/carrosseis/nutricao-no-tmo.md`
- `examples/carrosseis/alergia-pos-transplante.md`
- `examples/carrosseis/vacinas-pos-tcth.md`

Padrão: **situação concreta → por que importa → orientação geral → limites/variabilidade → quando conversar com a equipe**.

## Regra de escolha

Escolha o exemplo cuja combinação seja mais próxima em:
1. público;
2. objetivo;
3. risco editorial;
4. tipo de raciocínio necessário;
5. densidade técnica;
6. função visual.

Se o tema for clínico moderado/alto, **a biblioteca não substitui pesquisa de evidência atual**. Ela calibra comunicação; não valida claims.

## O que extrair dos exemplos

- estrutura narrativa;
- quantidade de informação por slide;
- transições entre conceito e consequência prática;
- tipo de metáfora;
- tom emocional;
- hierarquia tipográfica;
- relação texto/infográfico/foto;
- estilo de fechamento e CTA.

## O que não copiar

- frases inteiras sem necessidade;
- números clínicos ou intervalos sem revalidação;
- recomendações de um post antigo como se fossem atuais;
- imagens de pacientes/pessoas como template genérico;
- erros ou simplificações clínicas eventualmente presentes no material de referência.

## Regra de cruzamento

A **âncora editorial** define como organizar a ideia. A **âncora visual** define como apresentá-la.

Exemplos:
- quimerismo para pacientes → Dicionário do Transplante + VIS-002;
- medo antes do TCTH → Jornada de um Transplante + VIS-001 ou REEL-001;
- guideline novo → exemplo didático adequado + VIS-003;
- convite para aula → VIS-004;
- post institucional → VIS-005;
- chamada de carrossel → STORY-001.

Consultar `references/logica_de_roteamento_visual.md` antes de sugerir foto, vídeo ou capa.
